# Data Flow Diagram — Wattanapat PDF

```
 ผู้ใช้ ──เลือก/ลากไฟล์──▶ [UI Shell (PySide6)] ──IPC (anonymous pipe, ในเครื่อง)──▶ [Processing Engine (process แยก)]
                                │                                                          │
                                │ แสดงตัวอย่าง/ความคืบหน้า                                  │ อ่านไฟล์ต้นทาง (อ่านอย่างเดียว)
                                ▼                                                          ▼
                         หน้าจอ / ตัวอย่างภาพ                              Sandbox Temp: %LOCALAPPDATA%\WattanapatPDF\sandbox\session-*
                                                                                           │ (ผลลัพธ์ชั่วคราว)
                                                                                           ▼
                                                                          ไฟล์ปลายทางใหม่ (โฟลเดอร์ที่ผู้ใช้ยืนยัน, ไม่เขียนทับต้นฉบับ)
```

| ข้อมูล | ที่เก็บ | อายุ | ออกนอกเครื่อง |
|---|---|---|---|
| เนื้อหา/ชื่อไฟล์เอกสาร | หน่วยความจำของ Engine + Sandbox | จนปิดโปรแกรม / กดล้าง | ไม่ |
| รหัสผ่านไฟล์ | หน่วยความจำเท่านั้น | ระหว่างทำงาน | ไม่ |
| ชุดการตั้งค่า, ค่าตั้งโปรแกรม | `%APPDATA%\WattanapatPDF\settings.json` | จนผู้ใช้ลบ | ไม่ |
| รายการไฟล์ล่าสุด (เฉพาะที่ผู้ใช้เลือก, ปิดได้) | settings.json | จนผู้ใช้ล้าง | ไม่ |
| บันทึกข้อผิดพลาด | `%APPDATA%\WattanapatPDF\logs\errors.log` | หมุนเวียน ≤ 256 KB×3 | ไม่ (ผู้ใช้ส่งเองได้) |
| ตรวจอัปเดต (ปิดเป็นค่าเริ่มต้น) | HTTPS ไปยัง URL ที่ผู้ดูแลกำหนด | ครั้งที่สั่ง | ส่งเฉพาะเลขเวอร์ชัน |

Engine ไม่มีโค้ดเรียกเครือข่าย ไลบรารีทั้งหมดเป็นโอเพนซอร์สที่ทำงานในเครื่อง
