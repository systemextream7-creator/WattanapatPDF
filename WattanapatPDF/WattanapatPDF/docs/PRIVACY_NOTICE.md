# ประกาศความเป็นส่วนตัว — Wattanapat PDF

1. โปรแกรมประมวลผลเอกสารบนเครื่องของคุณทั้งหมด **ไม่อัปโหลดหรือส่งเนื้อหาเอกสารออกนอกเครื่อง**
2. ไฟล์ชั่วคราวอยู่ในโฟลเดอร์ Sandbox ของโปรแกรม และถูกลบเมื่อปิดโปรแกรม คุณกด “ล้างไฟล์ชั่วคราวทันที” ได้ที่หน้า ความปลอดภัย
3. โปรแกรมเก็บเฉพาะ: ค่าตั้งโปรแกรมและชุดการตั้งค่า (ไม่มีชื่อไฟล์/รหัสผ่าน), รายการไฟล์ล่าสุดที่คุณเลือก (ปิดและล้างได้), บันทึกข้อผิดพลาดที่ไม่มีชื่อไฟล์ เนื้อหา หรือรหัสผ่าน
4. การตรวจอัปเดตปิดไว้เป็นค่าเริ่มต้น หากเปิด จะส่งเฉพาะหมายเลขเวอร์ชันผ่าน HTTPS
5. การเข้ารหัสไฟล์ใช้ AES-256 รหัสผ่านไม่ถูกบันทึกลงดิสก์

**ข้อสงวน:** เอกสารนี้อธิบายพฤติกรรมของโปรแกรม ไม่ใช่การรับรองการปฏิบัติตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) องค์กรควรให้ฝ่ายกฎหมายหรือผู้เชี่ยวชาญตรวจสอบก่อนใช้งานจริง
